## 📌 Project Overview

This project provides a complete, distraction-free computer-based test (CBT) mock exam interface containing **500 verified English Vocabulary / Synonym questions (Question 1 to Question 500)** derived directly from official previous year exam papers.

The entire application runs inside **ONE single standalone `.html` file** with **zero external dependencies, zero CDNs, and zero internet connection required**.

## ✨ Key Features

### 🎯 1. 500 Real Exam Questions (Q1 to Q500)
- Questions sourced strictly from solved competitive exam papers:
  - **SSC**: CGL, CHSL, MTS, CPO, GD
  - **UPSC**: NDA & NA, CDS
  - **Teaching & Others**: KVS PRT, DSSSB TGT/PGT, High Court RO, State Exams
- Exact source, shift, and date information displayed alongside each question.

### 🎨 2. Premium Test Interface (Testbook & TCS iON Style)
- **Header**:
  - Embedded Polai Education Hub transparent logo.
  - Branded header badge: `ENGLISH VOCABULARY MOCK TEST (Q1 - 500)`.
  - **🎬 INTRO SLIDE**: Re-open the welcome and instruction screen anytime.
  - **🎯 Live Score Tracker**: Displays current score out of 500 in real-time.
  - **✅ Correct & ❌ Wrong Indicators**: Instant performance feedback counters.
  - **⛶ FULL SCREEN Mode**: Seamless browser fullscreen toggle.
- **Large & High-Contrast Typography**:
  - English question displayed in bold crimson red (`#b91c1c`) for clear readability.
  - Source tag indicating exact previous year exam reference.

### 🔲 3. 2 × 2 Option Cards (Responsive Layout)
- 4 large, spacious, rounded option cards (`A`, `B`, `C`, `D`).
- Automatically shifts from a 2 × 2 desktop grid to a 1 × 1 mobile layout.
- Immediate option lock on click to preserve exam integrity.
- Visual state changes:
  - **Correct Option**: Highlighted in vibrant green with green badge (`#15803d`).
  - **Wrong Selection**: Highlighted in soft red with red badge (`#b91c1c`).

### 💡 4. Detailed Answer & Notes Panel
- **📖 ANSWER & NOTES** section unlocked upon answering each question.
- Comprehensive breakdown including:
  - Identification of the target vocabulary word and its primary synonym.
  - Detailed definitions and contextual meanings of all four options (`A`, `B`, `C`, `D`).
  - Official previous year exam source citation.

### 🧭 5. Intuitive Fixed Bottom Navigation
- **🏠 HOME**: Quickly navigate back to the introductory welcome screen.
- **← PREVIOUS**: Return to earlier questions while safely retaining your selected answer.
- **💡 SHOW ANSWER & NOTES**: Smoothly scroll down to the explanation panel.
- **Go to Dropdown (`Q 1` to `Q 500`)**: Jump directly to any of the 500 questions in an instant.
- **Font Controls (`A−`, `Reset`, `A+`)**: Real-time scalable font sizing for question and options.
- **NEXT →**: Advance seamlessly to the next question on the exact same page without browser reloading or redirects.

### 🏁 6. Interactive Welcome & Completion Screens
- **Intro Screen**: Welcome modal introducing the test instructions, question count, and a prominent `🎯 START MOCK TEST` button.
- **Completion Screen**: Triggered after completing Question 500, displaying total score, correct count, incorrect count, percentage accuracy, and restart options.

## 🚀 How to Run

### Method 1: Local Offline Usage (Simplest)
1. Download or clone this repository.
2. Double-click the file:
   ```bash
   POLAI_EDUCATION_HUB_MOCK_TEST.html
   ```
3. It will open instantly in any modern web browser (**Google Chrome, Microsoft Edge, Mozilla Firefox, Safari, Opera**).
4. No internet connection or installation required!

### Method 2: Host Free on GitHub Pages
1. Go to your repository settings on GitHub (`Settings` > `Pages`).
2. Under **Build and deployment** > **Branch**, select `main` (or `master`) and folder `/ (root)`.
3. Rename `POLAI_EDUCATION_HUB_MOCK_TEST.html` to `index.html` (or link directly to the file).
4. Save, and your mock test will be live online for students worldwide!
